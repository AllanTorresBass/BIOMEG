# Registros

**Opened:** the menu only. No registry form was opened. These are master-data commands the public catalog did not name.

| Command | What the name establishes |
|---|---|
| Registro de Médicos | A physician master. The invoice has a Médico dropdown, so this registry is the likely source |
| Registro de Empresas | A company master. Ingreso Empresa and convenio-as-company both need it |
| Registro de Proveedores | Suppliers. Used by purchases and cuentas por pagar |
| Registro de Reactivos y Servicios | Reagents and services as catalog items |
| Registro de Equipos | Equipment. Distinct from the analyzer poster |
| Registro de Parásitos | Parasitology master |
| Registro de Antibióticos | Antibiotic master |
| Registro de Microorganismo | Organism master. The menu label is singular |
| Registro de Muestra de Bacteriología | Bacteriology sample master |
| Registro de Observaciones de Bacteriología | Bacteriology comment master |

## How this sits against the earlier notes

The public feature list stopped at patients, exams, results, and billing. This menu adds inventory masters, supplier masters, and a bacteriology set (parasites, antibiotics, organisms, samples, and observations).

Mantenimiento has **Agregar Nota de Bacteriología**, which is a different command from Registro de Observaciones de Bacteriología. Both exist. Neither screen was opened.

None of these labels is a column name. A physician row, a reagent row, and an organism row are implied. Their fields are not on screen.
