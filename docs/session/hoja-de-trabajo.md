# Hoja de Trabajo y Resultados

**Opened:** the menu only. None of these commands was followed into a form. A result preview was also open, and which command reached it is not confirmed. See [print-preview.md](print-preview.md). The toolbar repeats Hoja de Trabajo and Cargar Resultados.

| Command | Reading | Screen |
|---|---|---|
| Hoja de Trabajo | Worklist for the bench | Not opened |
| Cargar Resultados | Manual result entry. Matches the founder’s “carga de resultados” | Not opened |
| Imprimir por Paciente | Print the patient’s report | The preview is the likely destination. Not confirmed by clicking this item |
| Imprimir Prueba Individual | Print one test rather than the whole order | Not opened |
| Status de Impresión | A state for whether something has been printed | Not opened. Values of that state are unknown |
| Imprimir Referidos | Print work that was referred out, or a referral list | Not opened. Administrativo also has Relación de Referidos |
