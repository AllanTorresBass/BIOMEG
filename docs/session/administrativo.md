# Administrativo

**Opened:** the menu only. No administrative form was opened except Facturación de Consultas, which lives under Pacientes and is documented separately. The toolbar also has Presupuesto and Cierre Caja.

Labels below are transcribed from the open menu. One label is cut by the edge of the menu.

| Command | Reading |
|---|---|
| Re-Imprimir Orden de Entrega | Reprint a delivery order |
| Re-Imprimir Orden Empresa | Reprint a company order |
| Re-Imprimir Factura | Reprint an invoice. Implies the original is stored |
| Re-Imprimir Retenciones | Reprint a retention receipt |
| Re-Imprimir Nota de Crédito | Reprint a credit note |
| Re-Imprimir Nota de Débito | Reprint a debit note |
| Cobros Cashea | Cashea collections. A named command, not only a marketing bullet |
| Nota de Crédito | Issue a credit note. Separate from reprinting one |
| Nota de Débito | Issue a debit note |
| Reversar Relación | Reverse a “relación”. Which document a relación is was not opened |
| Agregar Abono | Add an installment or partial payment. The invoice totals include Abono and Resta |
| Registro de Pagos | Record payments |
| Cierre de Caja | Cash closing. Also a toolbar button |
| Cierre Mensual | Month-end close |
| Generar Presupuesto | Create a quote. Also a toolbar button. Reportes has Lista de Presupuestos |
| Relación de Referidos | A referral listing. Hoja de Trabajo has Imprimir Referidos |
| Generar Relación de Paciente | The last word is cut off on the capture. It may continue. Do not expand it |
| Cuentas por Cobrar | Receivables |
| Cuentas por Pagar | Payables |
| Tipos de Retenciones (ISLR) | Retention types for the Venezuelan income-tax withholding |
| Ordenes de Compra | Purchase orders. Reportes repeats this under Lista de Compras |
| Restar Inventario | Decrease stock. The earlier public notes had no inventory module |

## How this sits against the earlier notes

[Billing and payments](../modules/billing-and-payments.md) now has commands beyond Cashea and a multi-currency total: credit notes, debit notes, reprints, abonos, cash close, month close, ISLR retention types, and Cashea as its own collections command.

Inventory, purchase orders, and payables were absent from the public catalog. They are menu commands here. Their screens were not opened, so field lists stay unknown.

Reprint commands are the evidence that invoices, retentions, and notes are stored and can be emitted again. They are not evidence of an audit trail of who reprinted them. Auditoría is a separate command under Mantenimiento.
