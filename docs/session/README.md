# SICOEXC live session, 30 October 2026

This folder records what was open in the current program. It is not the proposal for the new application. The map is [../README.md](../README.md). The proposal is [../product/README.md](../product/README.md).

This folder is the primary record of a running copy of **Menú Principal del Sistema de Control de Exámenes Clínicos (SICOEXC)**. It corrects the public-source dossier, which could not see the application menus. The marketing site still describes version 9.0. This session advertises version 10.

Sources, kept outside the repository because one preview contains a real patient:

- `captures/home.PNG` and `captures/print.PNG`
- `screenshots.pptx`, fifteen screen images

**Privacy.** Patient name, cédula, age, and telephone from the print preview are not copied here. Laboratory identity and field labels are.
